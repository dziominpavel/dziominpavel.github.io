# Мои приложения

Статический сайт-каталог готовых приложений для скачивания: https://dziominpavel.github.io

Каждое приложение — отдельный публичный репозиторий, который публикует артефакты в
GitHub Releases и держит в корне файлы контракта (`store.yaml`, `screenshots/`,
`version`, иконка). Этот репозиторий лишь читает эти данные и генерирует витрину.

## Как это устроено

- `registry.yaml` — реестр проектов (ключ = слаг страницы приложения);
- `generate.py` — генератор статики на Python (без фреймворков): читает реестр,
  `store.yaml` и скриншоты проектов, версию/размер/дату/счётчик берёт из
  GitHub API (`releases.latest`);
- `templates/` — HTML-шаблоны витрины (только русский язык);
- `static/` — CSS и JS (тёмная тема по умолчанию, переключатель темы);
- `.github/workflows/` — CI: cron каждые 30 минут + при изменении `registry.yaml`,
  генерация статики и деплой на GitHub Pages.

## Локальное превью

```bash
python generate.py
```

Сгенерированная статика появляется в `_site/` (не коммитится).

## Как добавить приложение

1. В репозитории приложения выполнить контракт: `store.yaml`, `screenshots/`
   (3–5 изображений единого размера), иконка png 512×512, файл `version`.
2. Опубликовать релиз release-скриптом (тег `vX.Y.Z` + ассеты из `dist/`).
3. Добавить одну запись в `registry.yaml` этого репозитория.

После ближайшей синхронизации CI приложение появится на витрине.
