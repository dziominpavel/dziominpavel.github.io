## MODIFIED Requirements

### Requirement: Версия берётся из файла version
Release-скрипт MUST читать версию из файла `version` проекта (формат `MAJOR.MINOR.PATCH`) и создавать git tag вида `vX.Y.Z` (с префиксом `v`). Версия в имени тега, имени релиза и имени артефакта MUST совпадать. Если имя ассета верхнего уровня `dist/` содержит версию, не совпадающую с выпускаемой, публикация MUST завершиться ошибкой до push ветки, создания тега и публикации; вывод MUST перечислить виновные файлы и указать, что ассеты нужно пересобрать либо убрать в `dist/archive`. Ассет, в имени которого версии нет вовсе, чужой версии не содержит — он остаётся допустимым и приводится к конвенции имён. Файл `version` отсутствует ни в одном из 7 проектов не MUST — для проектов, где его нет, он MUST быть добавлен как часть внедрения.

#### Scenario: Текущая версия уже запущена
- **WHEN** тег `vX.Y.Z` из файла `version` уже существует
- **THEN** скрипт MUST завершиться с понятной ошибкой и MUST NOT перезаписывать существующий тег или релиз

#### Scenario: Файл version отсутствует
- **WHEN** release-скрипт запущен в проекте без файла `version`
- **THEN** скрипт MUST завершиться с ошибкой, указывающей на отсутствие файла

#### Scenario: В dist/ остался ассет прошлой версии
- **WHEN** фаза публикации запущена, версия из файла `version` равна `0.3.0`, а в верхнем уровне `dist/` лежит `Project-0.2.0.apk`
- **THEN** скрипт MUST завершиться ошибкой с перечислением виновного файла, тег и релиз MUST NOT быть созданы, ветка MUST NOT быть запушена

#### Scenario: Ассеты разных версий в одном dist
- **WHEN** в `dist/` одновременно лежат `Project-0.3.0.apk` и `Project-0.2.0.apk`, а выпускается `0.3.0`
- **THEN** скрипт MUST завершиться ошибкой с перечислением обоих файлов и MUST NOT публиковать ни один из них

#### Scenario: Ассет без версии в имени
- **WHEN** в `dist/` лежит ассет вида `Project-release-latest.apk` — версия в имени отсутствует, других ассетов с чужой версией нет
- **THEN** публикация MUST выполняться, а имя такого ассета приводится к конвенции `<Project>-<version>.apk`
