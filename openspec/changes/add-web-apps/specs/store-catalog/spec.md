## MODIFIED Requirements

### Requirement: Структура страниц
Витрина MUST состоять из: главной страницы (сетка карточек + фильтр каталога с сегментами «Все», Android, Windows, «Веб» + блок «Веб-приложения»), отдельной страницы на каждое скачиваемое приложение (`/<slug>/`), страниц веб-приложений (`/apps/<slug>/`), страницы «О проекте». Язык витрины — только русский. Навигация между страницами MUST быть доступна с каждой страницы.

#### Scenario: Фильтр по платформе
- **WHEN** посетитель выбирает платформу Android на главной
- **THEN** отображаются только карточки приложений, у которых есть ассеты Android, а блок «Веб-приложения» скрыт

#### Scenario: Сегмент «Веб»
- **WHEN** посетитель выбирает сегмент «Веб» на главной
- **THEN** отображается только блок «Веб-приложения», а сетка скачиваемых приложений скрыта

#### Scenario: Страница приложения
- **WHEN** посетитель открывает `/<slug>/`
- **THEN** он видит: полное описание, обязательный блок системных требования (если задан), галерею скриншотов, версию, размер, дату, счётчик скачиваний, кнопки скачивания по каждой доступной платформе, ссылку «Исходники» на GitHub-репозиторий

#### Scenario: Страница веб-приложения
- **WHEN** посетитель открывает `/apps/<slug>/`
- **THEN** он видит веб-приложение и навигацию обратно в каталог; страница включена в sitemap

#### Scenario: Блок веб-приложений виден на главной
- **WHEN** в реестре есть записи секции `web:`
- **THEN** на главной странице под каталогом скачиваемых приложений отображается блок «Веб-приложения» с их карточками; блок виден в сегментах «Все» и «Веб» и скрыт в сегментах Android/Windows
