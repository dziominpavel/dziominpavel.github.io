## MODIFIED Requirements

### Requirement: Структура страниц
Витрина MUST состоять из: главной страницы (единая сетка карточек — скачиваемые приложения, затем web-карточки + фильтр каталога с сегментами Все, Android, Windows, Web), отдельной страницы на каждое скачиваемое приложение (`/<slug>/`), страниц веб-приложений (`/apps/<slug>/`), страницы «О проекте». Язык витрины — только русский. Навигация между страницами MUST быть доступна с каждой страницы.

#### Scenario: Фильтр по платформе
- **WHEN** посетитель выбирает платформу Android на главной
- **THEN** отображаются только карточки приложений, у которых есть ассеты Android; web-карточки скрыты

#### Scenario: Сегмент Web
- **WHEN** посетитель выбирает сегмент Web на главной
- **THEN** в единой сетке отображаются только web-карточки, карточки скачиваемых приложений скрыты

#### Scenario: Страница приложения
- **WHEN** посетитель открывает `/<slug>/`
- **THEN** он видит: полное описание, обязательный блок системных требования (если задан), галерею скриншотов, версию, размер, дату, счётчик скачиваний, кнопки скачивания по каждой доступной платформе, ссылку «Исходники» на GitHub-репозиторий

#### Scenario: Страница веб-приложения
- **WHEN** посетитель открывает `/apps/<slug>/`
- **THEN** он видит веб-приложение и навигацию обратно в каталог; страница включена в sitemap

#### Scenario: Web-карточки в общей сетке
- **WHEN** в реестре есть записи секции `web:`
- **THEN** на главной странице в единой сетке после карточек скачиваемых отображаются web-карточки; они видны в сегментах Все и Web и скрыты в сегментах Android/Windows
