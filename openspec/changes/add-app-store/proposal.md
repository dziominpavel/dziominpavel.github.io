## Why

У владельца 7 готовых приложений (5 Android, 1 Windows zip, 1 exe), которые некуда выложить целиком: нет единой витрины с описаниями и кнопками скачивания, а файлы раздаются неструктурированно. Нужен собственный бесплатный «стор» — статический сайт-каталог, который автоматически собирает данные из репозиториев приложений и ведёт пользователя к скачиванию, без каких-либо платных сервисов и без ручной работы при каждом релизе.

## What Changes

- Этот репозиторий (`dziominpavel.github.io`, инициализирован локально) — статическая витрина «Мои приложения» (главная с карточками и фильтром платформ, страница на каждое приложение, страница «О проекте»), чистый HTML/CSS + минимум JS, dark-first с переключателем, только русский.
- Вводится единый контракт данных между приложениями и стором: `store.yaml` (name, description, обязательная icon, опциональные requirements), папка `screenshots/`, файл `version` — в каждом из 7 репозиториев приложений. Приложения ничего не знают о сторе: они просто кладут файлы по договорённости.
- Раздача файлов — через GitHub Releases (не через git): единый release-скрипт (копия в каждом репо) собирает артефакты из `dist/`, создаёт git tag `vX.Y.Z` из файла `version`, публикует релиз через gh CLI (потребуется установка GitHub CLI). Публикуется только текущая версия, история не переносится.
- Стор автоматически синхронизируется: CI в репо стора по cron обходит `registry.yaml`, читает `releases.latest` + `store.yaml` каждого проекта, генерирует статику (Python) и деплоит на GitHub Pages. Платформы кнопок определяются авто-детектом по ассетам релиза (`*.apk` / `*-win*.zip` / `*.exe`), несколько ассетов одной платформы показываются как варианты.
- Витрина показывает: иконку (буквенная заглушка при отсутствии), версию, размер, дату, счётчик скачиваний (download_count из GitHub API), ссылку «Исходники», подсказку про SmartScreen для неподписанных exe. Приложение без первого релиза скрывается целиком.
- Аналитика посещений — GoatCounter (бесплатный, без cookie); аккаунт регистрируется владельцем при реализации.
- Pilot-порядок внедрения: весь контракт и скрипты отрабатываются на FogMap, затем скриптом разносятся на остальные 6 проектов (YandexMusicDownloader, instagram-tracker через PyInstaller-exe, ChargeForecast, GymProgress, VoiceMind, Wishlot).
- Отложено на будущее (контракт резервирует место): changelog/history, автосъёмка скриншотов (adb), редиректы при переименовании слага.

## Capabilities

### New Capabilities

- `store-data-contract`: контракт данных стор↔приложения — обязательные файлы и поля в репозиториях приложений (`store.yaml`, `screenshots/`, `icon`, `version`), реестр `registry.yaml` в сторе, правила валидации и поведение при нарушении (skip с предупреждением, а не падение).
- `app-release-pipeline`: единый release-скрипт приложений — сборка артефактов в `dist/`, чтение версии из файла `version`, создание git tag `vX.Y.Z`, публикация GitHub Release с ассетами через gh CLI, предрелизные проверки (наличие иконки), форматы ассетов по платформам.
- `store-catalog`: витрина — сборка статики из контракта и GitHub API (генератор на Python), структура страниц (главная, страница приложения, «О проекте»), карточки и кнопки скачивания, авто-детект платформ, счётчики скачиваний, тема оформления, аналитика, деплой на GitHub Pages через CI по cron.

### Modified Capabilities

(нет — ни одна существующая capability FogMap не меняет своих требований; release-скрипт и контракт являются новыми возможностями, интеграция не меняет поведение приложения.)

## Impact

- Этот репозиторий `dziominpavel.github.io` (стор: шаблоны, генератор, registry.yaml, CI-workflow, GitHub Pages) — локально инициализирован, публикация remote на GitHub отдельной задачей;
- 7 репозиториев приложений: добавляются `store.yaml`, `screenshots/`, файл `version` (где отсутствует), иконка png, копия release-скрипта; в FogMap — расширение `build-apk.bat` вызовом release-скрипта.
- Инструменты: установка GitHub CLI (gh) на машину владельца; Python 3.14 (уже есть); аккаунт GoatCounter (регистрация владельца).
- GitHub: Releases вместо ручной раздачи, Actions (cron-синхронизация стора), Pages (хостинг витрины) — всё в бесплатных тарифах, репозитории публичные.
- Не затрагивается: поведение и код самих приложений (кроме сборочного скрипта FogMap), приватные данные, платные сервисы.
