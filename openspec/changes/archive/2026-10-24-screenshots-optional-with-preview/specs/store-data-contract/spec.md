# Spec Delta

## MODIFIED Requirements

### Requirement: Обязательные файлы контракта в репозитории приложения
Каждый репозиторий приложения, входящий в реестр стора, MUST содержать: файл `store.yaml` в корне, файл иконки png (512×512, путь указан в `store.yaml`), файл `version` (формат `MAJOR.MINOR.PATCH`). Папка `screenshots/` является опциональной и MAY содержать от 0 до 5 изображений единого формата; при 0 изображений папка MAY отсутствовать. Файл `store.yaml` MUST содержать поля: `name`, `description`, `icon`. Поле `requirements` (системные требования, одна строка) является опциональным. Поле `history` зарезервировано под changelog и в первой версии MUST оставаться пустым или отсутствовать. Если изображений больше пяти, стор MUST использовать первые пять и вывести предупреждение, не скрывая приложение.

#### Scenario: Валидный проект
- **WHEN** репозиторий из реестра содержит все обязательные файлы и поля
- **THEN** стор включает его данные в сборку витрины без предупреждений

#### Scenario: Отсутствует обязательное поле
- **WHEN** в `store.yaml` отсутствует поле `name`, `description` или `icon`
- **THEN** проект пропускается при сборке витрины с предупреждением в логе CI; сборка витрины MUST NOT падать

#### Scenario: Проект без скриншотов
- **WHEN** в репозитории нет папки `screenshots/` или в ней 0 изображений
- **THEN** приложение публикуется на витрине, а его страница показывает блок «Превью» вместо галереи

#### Scenario: Один или два скриншота
- **WHEN** в папке `screenshots/` лежит 1 или 2 изображения
- **THEN** приложение публикуется, а галерея показывает только эти изображения без добивки до трёх

#### Scenario: Больше пяти скриншотов
- **WHEN** в папке `screenshots/` лежит больше пяти изображений
- **THEN** публикуются первые пять, в лог выводится предупреждение, приложение остаётся на витрине
