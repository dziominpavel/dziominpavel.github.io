# Delta: store-web-apps (check-data-updated-consistency)

## ADDED Requirements

### Requirement: Сверка `updated` с последним коммитом файла данных
Сборка витрины MUST сверять календарную дату UTC поля `updated` объявленного файла данных web-записи (`data:`) с датой последнего коммита, тронувшего этот файл. Расхождение дат MUST печататься в лог сборки как предупреждение, содержащее слаг web-приложения, значение `updated` и дату коммита. Предупреждение MUST NOT менять дату web-карточки, содержимое собранной статики или код завершения сборки: источником даты карточки остаётся `updated`. Если дату коммита получить не удалось, сверка MUST пропускаться без предупреждения, а сборка и дата карточки MUST при этом не меняться. Сверка MUST выполняться только для web-записей с объявленным полем `data:`; web-запись без `data:` сверка MUST NOT требовать.

#### Scenario: `updated` отстаёт от последнего коммита данных
- **WHEN** web-запись объявляет `data: data/index.json`, поле `updated` равно `2026-10-06`, а последний коммит, тронувший этот файл, датирован `2026-10-07`
- **THEN** сборка печатает предупреждение со слагом и обеими датами, дата карточки остаётся `06.10.2026`, сборка завершается успешно и статика не меняется

#### Scenario: Даты совпадают
- **WHEN** календарная дата UTC поля `updated` равна календарной дате последнего коммита файла данных
- **THEN** предупреждение не печатается, дата карточки берётся из `updated` как обычно

#### Scenario: Коммит-дата недоступна
- **WHEN** дату последнего коммита файла данных получить не удалось (ошибка API, пустой ответ)
- **THEN** сверка пропускается без предупреждения, дата карточки берётся из `updated`, сборка завершается успешно

#### Scenario: Запись без файла данных
- **WHEN** у web-записи не объявлено поле `data:`
- **THEN** сверка не выполняется, дата карточки берётся из даты последнего коммита папки `web/` источника
