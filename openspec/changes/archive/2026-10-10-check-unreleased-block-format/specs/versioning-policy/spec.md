## ADDED Requirements

### Requirement: Проверка версионирования контролирует формат-контракт верхнего блока
Помимо сверки файла `version` с верхней секцией `CHANGELOG.md`, автоматическая проверка версионирования (`scripts/check-version.py`) MUST валидировать верхний блок секции `## [Unreleased]` — часть выше первой строки `###` — по формат-контракту, идентичному гейту release-скрипта: каждая непустая строка блока MUST быть либо жирной меткой категории (`**Добавлено**` и аналоги), либо буллетом; в блоке MUST быть не менее одного буллета; строка MUST быть не длиннее 140 символов; символ `` ` `` в блоке MUST NOT использоваться; секция с накопленными пунктами MUST NOT начинаться с `###` (верхний блок обязателен). Проверка MUST выполняться во всех режимах (`--all`, `--project`, самопроверка) и для проектов обоих треков. Нарушение MUST завершать проверку ненулевым кодом с перечислением каждой проблемы. Пустая секция `## [Unreleased]` (накопленных пунктов нет) формат-контрактом MUST NOT проверяться: это подсказка NO_BUMP, а не ошибка. Версионные секции, включая исторические, этой проверке MUST NOT подлежать.

#### Scenario: Нарушение контракта в одном из проектов
- **WHEN** в секции `## [Unreleased]` одного из проектов есть накопленные пункты, а до первой строки `###` лежат строки, не являющиеся жирными метками или буллетами, либо строка длиннее 140 символов, либо строка содержит символ `` ` ``
- **THEN** проверка завершается ненулевым кодом и перечисляет каждую проблему с указанием секции

#### Scenario: Секция с пунктами начинается с ###
- **WHEN** в секции `## [Unreleased]` есть накопленные пункты, но первая непустая строка начинается с `###`
- **THEN** проверка завершается ненулевым кодом с сообщением об отсутствии верхнего блока

#### Scenario: Пустая секция не ошибка
- **WHEN** в секции `## [Unreleased]` нет накопленных пунктов
- **THEN** формат-контракт не применяется, проверка печатает подсказку NO_BUMP и завершается кодом 0 (если прочие проверки сошлись)

#### Scenario: Исторические секции не проверяются
- **WHEN** верхняя секция `## [Unreleased]` валидна, а версионные секции ниже не содержат блока в формате контракта
- **THEN** проверка завершается кодом 0: версионные секции, включая исторические, формат-контрактом верхнего блока не проверяются
