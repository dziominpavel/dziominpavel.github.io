## 1. Гейт в эталоне release-скрипта

- [x] 1.1 В `scripts/release.ps1`, фаза публикации, шаг 2 (отбор ассетов `dist/`): для каждого ассета собрать версии из имени паттерном `(?<![\d.])\d+\.\d+\.\d+(?!\d)`; если среди них нет `$Version` — `Fail` с перечислением виновных файлов, с указанием пересобрать ассеты либо убрать их в `dist/archive` и с пометкой, что тег и релиз не создаются. Верификация: в фикстуре с `ChargeForecast-0.2.0.apk` при `$Version=0.3.0` скрипт завершается ошибкой с именем файла **до** шага push ветки; с ассетом `FogMap-release-latest.apk` (без версии) ошибки нет.
- [x] 1.2 Поднять `$SCRIPT_VERSION` до `1.4.2` (`1.4.0` → дефектный `1.4.1` → `1.4.2` после исправления границы паттерна). Верификация: в эталоне строка `$SCRIPT_VERSION = "1.4.2"`, а dry-run `sync-release.ps1` помечает копии всех 7 проектов как устаревшие `v1.4.1`.
