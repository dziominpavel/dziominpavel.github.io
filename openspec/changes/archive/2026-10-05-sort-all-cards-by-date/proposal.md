## Why

Карточки на главной сейчас идут двумя блоками: сначала скачиваемые по дате релиза, потом web-карточки. Посетитель не видит общей картины «что обновлялось последним». Дополнительно web-запись без `data:` (InstagramTracker Web) показывает дату сборки витрины (`datetime.now()` каждые 30 мин) как «Обновлено», поэтому выглядит вечно самой свежей, хотя код не менялся.

## What Changes

- Главная страница показывает единую ленту всех карточек (скачиваемые + web вперемешку), отсортированную по убыванию даты обновления: новые сверху, старые внизу. Порядок `registry.yaml` по-прежнему определяет только состав, а не порядок.
- Дата web-карточки без `data:` берётся из последнего коммита, тронувшего папку `web/` источника (GitHub API `commits?path=web`), а не из даты сборки витрины. Fallback-цепочка: коммит по `path=web` → дата HEAD локального клона → дата сборки + WARN.
- Web-карточка с `data:` (Benchmark) без изменений: дата по-прежнему из `data/index.json:updated`.
- Фильтры (`Все` / `Android` / `Windows` / `Web`), hero-статистика, sitemap и формат дат (`fmt_date`) без изменений в поведении; счётчики фильтра продолжают считать по сегментам.

## Capabilities

### New Capabilities
- None

### Modified Capabilities
- `store-catalog`: порядок карточек главной — единая лента по убыванию даты вместо двух групп (скачиваемые, затем web).
- `store-web-apps`: источник даты web-карточки без `data:` — последний коммит `web/` вместо даты сборки витрины; положение web-карточек — в общей ленте по дате вместо «сразу после скачиваемых».

## Impact

- `generate.py`: `collect_web_projects` (источник даты), `render_site` / `sort_by_date` (единый рендер ленты), `main --json` (порядок вывода).
- `tests/test_generate.py`: `test_render_home_sorted_by_date`, кейсы даты web без `data:`; новый мок GitHub API `commits?path=web`.
- `tests/validate_site.py`: при необходимости проверка порядка в единой сетке.
- Спеки: дельты `store-catalog` и `store-web-apps`; скриншоты/доки не затрагиваются. Поведение для Benchmark и скачиваемых карточек совместимо.
