# Spec Delta

## MODIFIED Requirements

### Requirement: Два трека проектов
Каждый проект MUST относиться к одному из двух треков. Релизный трек: проект выходит релизом и его версия растёт по описанным правилам. Статический трек: проект не выпускает релизов, его версия MUST оставаться замороженной (в том числе фиксированной строкой в манифесте проекта), при этом `CHANGELOG.md` с секцией `[Unreleased]` остаётся обязательным.

#### Scenario: Статический проект
- **WHEN** проект статического трека (например, проект без релизного конвейера) получает изменения
- **THEN** `CHANGELOG.md` пополняется, а версия остаётся неизменной и не публикуется как релиз

#### Scenario: Проект статического трека переходит в релизный
- **WHEN** проект получает release-конвейер и публикует первый релиз
- **THEN** он начинает соблюдать релизные правила с этого момента, changelog сохраняет прошлую историю

#### Scenario: Витрина на релизном треке
- **WHEN** репозиторий витрины «Мои приложения» выпускает релиз
- **THEN** версия хранится в файле `version`, а git-тег `vX.Y.Z` и GitHub Release публикуются по релизным правилам
