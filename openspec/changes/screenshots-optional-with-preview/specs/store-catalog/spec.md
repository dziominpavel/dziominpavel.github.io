# Spec Delta

## ADDED Requirements

### Requirement: Блок «Превью» при отсутствии скриншотов
Если у приложения нет ни одного подготовленного скриншота, страница MUST показывать в месте галереи секцию «Превью» с текстовым сообщением о том, что скриншоты появятся позже. Блок MUST NOT содержать изображений и фейковых скриншотов. При наличии хотя бы одного подготовленного скриншота MUST показываться галерея с реальными изображениями без добивки до трёх.

#### Scenario: Нет ни одного скриншота
- **WHEN** у приложения нет исходных скриншотов
- **THEN** страница показывает секцию «Превью» с текстом, а в секции нет тега `<img>` и фейковых изображений

#### Scenario: Один или два скриншота
- **WHEN** у приложения подготовлен один или два скриншота
- **THEN** страница показывает галерею только с этими изображениями, блок «Превью» отсутствует

#### Scenario: Все изображения не удалось подготовить
- **WHEN** исходные скриншоты есть, но ни один не удалось преобразовать в превью
- **THEN** страница показывает блок «Превью», а не пустую галерею

#### Scenario: Оформление в обеих темах
- **WHEN** посетитель переключает тёмную или светлую тему
- **THEN** блок «Превью» использует цвета темы витрины и не требует загрузки изображений
